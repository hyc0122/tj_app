# Tianjiang App

[简体中文](../README.md) · [English](./README.en.md) · [日本語](./README.ja.md) · [Русский](./README.ru.md) · [ไทย](./README.th.md) · [Tiếng Việt](./README.vi.md) · [繁體中文](./README.zhtw.md)

Tianjiang เป็นไคลเอนต์ Windows สำหรับการผลิตละครมังงะด้วย AI ตั้งแต่จัดระเบียบเรื่อง บท สินทรัพย์ สตอรีบอร์ด คิวการสร้าง และศูนย์งาน ซอร์สไคลเอนต์ Apache-2.0 เผยแพร่ที่ [hyc0122/tj_app](https://github.com/hyc0122/tj_app) ส่วนบัญชีกลาง บริการทีม ระบบผู้ดูแล และการปรับใช้ไม่อยู่ในคลังสาธารณะ

## ความต้องการของระบบ

- แพลตฟอร์มรุ่นที่ควบคุมในปัจจุบันคือ Windows x64
- การพัฒนาจากซอร์สต้องใช้ Node.js 24.13.1 และ Yarn 1.22.22
- ชื่อไฟล์ติดตั้งคือ `天将漫创-<version>-win-x64-setup.exe`

## การติดตั้ง

1. รับไฟล์ติดตั้ง Windows x64 จากช่องทาง Release ทางการที่ผู้ดูแลประกาศ อย่าใช้ลิงก์ที่คาดเดาหรือมิเรอร์ที่ไม่ได้ตรวจสอบ
2. เรียกใช้ตัวติดตั้งและเลือกโฟลเดอร์เป้าหมาย โปรแกรมจะติดตั้งลงในโฟลเดอร์นั้นโดยตรง
3. แพ็กเกจรวม Microsoft VC++ x64 สำหรับติดตั้งแบบออฟไลน์แล้ว
4. เปิด Tianjiang และเข้าสู่ระบบด้วยบัญชีกลาง ข้อมูลเข้าสู่ระบบภายในเครื่องแบบเก่าไม่ใช้แล้ว

## การใช้งานครั้งแรก

1. เปิด **การตั้งค่า → บริการโมเดล** แล้วตั้งค่าผู้ให้บริการข้อความ รูปภาพ และวิดีโอ
2. สร้างโครงการใหม่หรือนำเข้านิยายหรือบท
3. ทำงานตามลำดับเรื่อง บท สินทรัพย์ สตอรีบอร์ด และวิดีโอ พร้อมติดตามงานระยะไกลในศูนย์งาน
4. โครงการและโมเดลส่วนบุคคลแยกตามบัญชี ส่วนสิทธิ์ทีม ล็อก และการซิงค์มาจากบริการกลาง

## ผู้ให้บริการโมเดล

- URL ชื่อโมเดล และคีย์จะอยู่ในการตั้งค่าภายในเครื่องของบัญชีปัจจุบัน
- ห้ามส่งข้อมูลลับไปยังบันทึก การซิงค์ทีม หรือไดเรกทอรีของบัญชีอื่น
- ตรวจสอบผู้ให้บริการข้อความ รูปภาพ และวิดีโอแยกกัน
- ไคลเอนต์ตรวจทั้ง Stable และ Beta โดย Stable รุ่นใหม่เป็นข้อบังคับเมื่อเข้าสู่ระบบ ส่วน Beta เป็นรุ่นทดสอบที่ผู้ใช้เลือกเอง
- แค็ตตาล็อก Windows x64 อยู่ที่ `https://cdn.j11.com.cn/desktop/{stable|beta}/windows/x64` และหน้าเว็บไม่รับ URL อัปเดตที่กำหนดเอง

## การย้ายข้อมูล

รหัสเครื่องปัจจุบันคือ `tianjiang` และโปรโตคอลเดสก์ท็อปคือ `tianjiang://` การย้ายแบบทางเดียวที่มีเวอร์ชันจะอัปเกรดรหัสผู้ให้บริการ การอ้างอิงโมเดล โฟลเดอร์บัญชี และไฟล์แบบไดนามิก พร้อมสำรอง SQLite ก่อนเขียน หากตรวจสอบไม่ผ่านจะหยุดโดยไม่เขียนทับข้อมูลต้นฉบับ

## การพัฒนาและตรวจสอบ

```powershell
cd app
yarn install --frozen-lockfile
yarn dev
yarn lint
yarn build
```

ทดสอบ App ที่แก้ไขด้วย `node --import tsx --test <ไฟล์ทดสอบ>`; Beta เผยแพร่จาก `.github/workflows/app-release.yml` และ Stable จาก `.github/workflows/app-stable-release.yml`

## การแก้ไขปัญหา

- แยกปัญหาเครือข่ายบริการกลาง การยืนยันตัวตน และรันไทม์ภายในเครื่อง
- หากโมเดลล้มเหลว ให้ตรวจ URL คีย์ ชื่อโมเดล บัญชี รหัสข้อผิดพลาด และ request ID
- เมื่อการย้ายข้อมูลขัดแย้ง ให้เก็บ `migration-backups` และโฟลเดอร์ recovery ไว้
- ปัญหาตัวติดตั้งควรตรวจว่าใช้แพ็กเกจ Windows x64 ทางการ
