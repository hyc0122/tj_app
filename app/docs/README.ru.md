# Tianjiang App

[简体中文](../README.md) · [English](./README.en.md) · [日本語](./README.ja.md) · [Русский](./README.ru.md) · [ไทย](./README.th.md) · [Tiếng Việt](./README.vi.md) · [繁體中文](./README.zhtw.md)

Tianjiang — локальный клиент для создания AI-манга-драм: подготовка истории, адаптация сценария, персонажи и сцены, раскадровка и генерация видео. Проекты и личные настройки моделей хранятся в локальной области текущей центральной учётной записи.

## Требования

- Контролируемая платформа выпуска: Windows x64.
- Для разработки нужны Node.js 24.13.1 и Yarn 1.22.22.
- Имя установщика: `天将漫创-<version>-win-x64-setup.exe`.

## Установка

1. Получите Windows x64 установщик через официальный канал Release, указанный сопровождающими. Не используйте неподтверждённые зеркала или вымышленные URL.
2. Запустите мастер и выберите папку: приложение устанавливается непосредственно в неё.
3. Microsoft VC++ x64 включён в пакет и устанавливается без сетевой загрузки.
4. Запустите Tianjiang и войдите через центральную учётную запись; старые локальные данные входа больше не действуют.

## Первый запуск

1. Откройте **Настройки → Сервисы моделей** и настройте поставщиков текста, изображений и видео.
2. Создайте проект или импортируйте роман либо сценарий.
3. Выполняйте этапы истории, сценария, ресурсов, раскадровки и видео; удалённые задачи отслеживаются в центре задач.
4. Личные проекты и настройки разделены по аккаунтам, а права команды и синхронизация определяются центральным сервисом.

## Поставщики моделей

- Адреса, имена моделей и ключи относятся к локальным настройкам активного аккаунта.
- Секреты не должны попадать в журналы, командную синхронизацию или каталог другого пользователя.
- Проверяйте текстовые, графические и видеомодели отдельно.
- Для проверки обновлений нужен `TIANJIANG_UPDATE_MANIFEST_URL`; его отсутствие не блокирует рабочую область.

## Миграция данных

Текущий машинный идентификатор — `tianjiang`, протокол рабочего стола — `tianjiang://`. Версионная односторонняя миграция обновляет идентификаторы, ссылки моделей, каталоги аккаунтов и динамические файлы. Перед записью создаётся резервная копия SQLite; при ошибке исходные данные не перезаписываются.

## Разработка и проверка

```powershell
cd app
yarn install --frozen-lockfile
yarn dev
yarn test:tianjiang
yarn lint
yarn build
```

## Устранение неполадок

- Разделяйте ошибки сети центрального сервиса, аутентификации и локального запуска.
- Для моделей проверьте URL, ключ, имя модели, активный аккаунт, код ошибки и ID запроса.
- При конфликте миграции сохраните `migration-backups` и recovery-каталоги.
- При ошибке установщика убедитесь, что используется официальный Windows x64 пакет.
