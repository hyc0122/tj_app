# 天将漫创 App

[简体中文](../README.md) · [English](./README.en.md) · [日本語](./README.ja.md) · [Русский](./README.ru.md) · [ไทย](./README.th.md) · [Tiếng Việt](./README.vi.md) · [繁體中文](./README.zhtw.md)

Tianjiang は、小説整理、脚本化、キャラクター／シーン素材、絵コンテ、動画生成を一つの流れで扱うローカル AI 漫画ドラマ制作クライアントです。プロジェクトと個人モデル設定は、ログイン中の中央アカウント専用のローカル領域に保存されます。

## 動作要件

- 現在の正式リリース対象は Windows x64 です。
- ソース開発には Node.js 24.13.1 と Yarn 1.22.22 が必要です。
- インストーラー名は `天将漫创-<version>-win-x64-setup.exe` です。

## インストール

1. 保守担当者が案内する正式 Release 経路から Windows x64 版を取得します。未確認の URL やミラーは使用しないでください。
2. インストーラーを実行し、保存先を選択します。アプリは選択したフォルダー直下に入ります。
3. Microsoft VC++ x64 ランタイムは同梱され、インストール時の追加ダウンロードは不要です。
4. 起動後は中央アカウントでログインします。過去文書のローカル既定アカウントは使用しません。

## 初回利用

1. **設定 → モデルサービス** で、文章・画像・動画の各プロバイダーを設定します。
2. プロジェクトを作成するか、小説／脚本を読み込みます。
3. 物語整理、脚本、素材、絵コンテ、動画の順に制作し、遠隔タスクはタスクセンターで確認します。
4. 個人プロジェクトとモデル設定はアカウントごとに分離され、チーム権限と同期状態は中央サービスが管理します。

## モデルプロバイダー

- エンドポイント、モデル名、キーは現在のアカウントのローカル設定に保存されます。
- 秘密情報をログ、チーム同期、別アカウントの領域へ入れてはいけません。
- 文章・画像・動画の各プロバイダーを個別に検証してください。
- 更新確認には `TIANJIANG_UPDATE_MANIFEST_URL` が必要ですが、未設定でも作業画面は利用できます。

## データ移行

現在の機械識別子は `tianjiang`、デスクトッププロトコルは `tianjiang://` です。旧データはバージョン付きの一方向移行で更新され、事前に SQLite バックアップを作成します。検証や解析に失敗した場合は元データを上書きせず停止します。

## 開発と検証

```powershell
cd app
yarn install --frozen-lockfile
yarn dev
yarn test:tianjiang
yarn lint
yarn build
```

## トラブルシューティング

- ログイン失敗は、中央ネットワーク、認証、ローカル実行環境の問題を分けて確認します。
- モデル失敗は、URL、キー、モデル名、現在のアカウント、エラーコード、リクエスト ID を確認します。
- 移行競合時は `migration-backups` と recovery フォルダーを保持し、データベースを削除しないでください。
- インストーラー問題では、正式な Windows x64 パッケージか確認してください。
