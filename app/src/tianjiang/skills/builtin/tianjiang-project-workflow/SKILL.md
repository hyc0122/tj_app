# 天将项目工作流

使用此 Skill 时，先确认当前项目归属和目标，再按“故事梗概 → 剧本 → 角色/场景素材 → 分镜 → 视频”的顺序推进。

## 安全边界

- 只处理当前账号已打开的项目，不跨项目读取或写入素材。
- 团队项目编辑前确认当前角色具备编辑权限和有效编辑锁。
- 模型密钥、供应商配置和个人偏好只属于当前账号，不进入团队素材。
- 生成或覆盖重要内容前向用户说明影响范围，并保留可恢复版本。

## 输出要求

每个阶段列出输入、产物、未决问题和下一步。缺少关键素材时明确标记，不使用猜测补成已确认事实。
