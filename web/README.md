# 天将漫创 Web

[简体中文](./README.md) · [English](./docs/README.en.md)

本目录是天将漫创桌面客户端的 Vue 前端，负责中央账号登录、工作台、项目制作流程、任务状态和本地设置界面。它通过同一安装包中的本地运行时工作，不应作为无认证的独立公网应用部署。客户端源码以 Apache-2.0 发布在 [hyc0122/tj_app](https://github.com/hyc0122/tj_app)，不包含中央服务和管理后台。

## 运行要求

- Node.js 24.13.1
- Yarn 1.22.22
- 正式用户请使用天将漫创 Windows x64 安装包；本目录命令面向源码开发。

## 安装与运行

```powershell
cd web
yarn install --frozen-lockfile
yarn dev
```

开发服务器不会自动打开浏览器。与 Electron 联调时，应由 App 启动本地服务并完成握手；前端桌面能力统一使用 `tianjiang://`。

## 首次使用

1. 在 App 中使用中央账号登录。
2. 进入设置页配置当前账号的文本、图片和视频模型供应商。
3. 在工作台创建或导入项目，按剧本、资产、分镜和视频流程制作。
4. 任务中心显示远端生成状态；团队项目的可写状态取决于中央权限与锁。

## 开发验证

```powershell
yarn test:tianjiang-ui
yarn type-check
yarn build
```

业务 UI 修改至少应运行上述三项。生成的 `dist` 只是前端构建产物，不等同于已验证的桌面安装包。

## 数据与安全边界

- 前端不持久化中央 JWT、刷新令牌或模型密钥。
- 供应商密钥由当前账号的本地运行时读取；不得进入日志、团队同步或其他账号。
- 更新清单地址由后台环境配置，前端不接受自定义更新 URL。
- 用户项目和 SQLite 数据不应写入前端源码或打包静态资源。

## Stable 与 Beta 更新

- App 同时读取固定的 Stable/Beta Windows x64 平台目录，Web 只展示经过本地运行时验证的结果。
- 新版 Stable 在登录阶段强制更新；Beta 是用户主动选择的可选测试版。
- Web `dist` 不单独发布更新，也不能把任意 URL 传给安装器。

## 故障排查

- 页面无法进入：区分中央 API 不可达、本地服务启动失败和认证失败。
- 通用 Network Error 不应提示管理员运行；请保留公共错误码和 request ID。
- 桌面操作无响应：确认 App 本地握手完成，且没有直接用普通浏览器打开构建文件。
- 更新提示缺失：由部署方检查后台更新清单配置，不在前端输入自定义地址。
